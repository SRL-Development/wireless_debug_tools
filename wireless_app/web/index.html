计算口径与边界

· 信号来源：本机 netsh 报告 dBm 时直接用；只有百分比时按 Windows 线性口径换算（RSSI ≈ 百分比/2 − 100），分辨率约 2 dB，不是仪表实测值。
· 漫游判定：以 BSSID 变化为准。同一 SSID 换 BSSID = 二层漫游；换 SSID = 跨 SSID 切换；换频段 = 跨频段漫游；关联消失 = 掉线。采样间隔就是判定分辨率。
· 切换耗时：给的是「上一次仍看到旧 BSSID」到「第一次看到新 BSSID」的观测差，上限等于采样间隔，不是空口抓包级时延；要精确测需专用网卡 + 抓包。
· 信道拥挤：指数 = 射频数 45 + 重叠对 20 + 利用率 35，按频率区间判重叠（40/80/160 MHz 会覆盖邻道），与「空口扫描」页同一套口径。
· 主动扫描代价：缓存里 BSS 少于 6 个时会自动补一次主动扫描（≥15 秒一次），扫描期间网卡会短暂切信道，可能 1-2 秒瞬断；落在扫描窗口内的事件会标注，判读时请剔除。
· 只测本机这一张网卡。手机、PDA 的漫游行为可能不同；要判定整层漫游质量，请用同一台机器按固定路线多走两遍，对比 CSV。

勘测会话与验收标准

怎么走测：先在右侧图纸上确认比例尺与朝向，拿着笔记本沿路线走，每到一点在图纸上点一下，程序会读取此刻的真实关联（SSID / BSSID / RSSI / 信道）与周边 BSS，把该点固化下来。 勾选「每个点位重新扫描」后每点都会独立采一次空口快照（推荐）；不勾选则复用最近一次扫描，多点会共用同一份干扰数据，只适合验证流程。 点位需要 ≥5 个才能做空间插值，≥15 个的结论才比较稳。

使用说明
安装、启动、典型操作与已知边界

安装与启动

  • 本程序为免安装单文件 exe，双击 WirelessNetOptimizer.exe 即可运行，不需要管理员权限，不需要联网
  • 启动后会弹出一个黑色控制台窗口并显示本机地址，同时自动打开默认浏览器访问 http://127.0.0.1:8765/
  • 若 8765 被占用，会自动顺延到 8766、8767… 以控制台显示的地址为准
  • 只监听 127.0.0.1，局域网内其他机器无法访问，符合内网离线要求
  • 关闭方式：在控制台按 Ctrl + C，或直接关闭控制台窗口
  • 可选参数：--port 9000 指定端口，--no-browser 不自动打开浏览器
  • 图纸与项目保存在 %APPDATA%\WirelessNetOptimizer\，卸载时删掉 exe 和这个目录即可，不留注册表项

热力图五步走（含 SSID 与实时重算）

  • 选 SSID：顶部下拉切换分析对象，或到「SSID 配置」绑定 AP、调整频段与接入门限；切换后热力图会自动重算
  • 图纸：用「示例楼层」直接体验、上传自己的 PNG/JPG 平面图，或点「绘制草图」从模板起手直接在画布上勾房间与隔墙
  • 比例尺：选「比例尺标定」，在图上拖出一段已知长度的线（例如走廊 10 米），在弹框里输入实际米数，程序自动算像素/米
  • 建模：用「绘制墙体」沿房间隔断拖线（材质决定穿墙衰减），用「放置 AP」点上 AP，右侧可逐台改型号、功率与天线增益
  • 打点与计算：用「录入实测点」在走测位置点击填入 RSSI；点「计算热力图」看覆盖率、盲区、低置信区与留一 RMSE
  • 实时联动：用「选择 / 移动」拖动 AP，热力图会即时给轻量预览，松手后自动按完整模型重算（可在左侧关闭「自动重算」改为手动）

绘图与渲染增强

  • 平滑色带：默认先在「数值域」做双线性插值、再映射颜色，消除低分辨率网格直接放大造成的色带阶梯；取消「平滑色带」可查看原始网格颗粒
  • 动态色标：右侧色标随「信号覆盖 / 有效 SINR」图层切换刻度，门限标记取当前 SSID 的接入门限（不再是写死的 -67 dBm）；SINR 图层显示 20 dB 参考线
  • 等值线：覆盖门限线与盲区边界线由模型网格经 marching-squares 求出，与色块同源；可分别开关，线旁标注门限值
  • 不透明度：左侧滑块调淡热力图层以便看清底图墙线；「导出 PNG」按同一不透明度合成，并内嵌色标、网格精度、传播模型与生成时间
  • 绘制辅助：画房间 / 隔墙 / 标比例尺时实时显示米数与角度，靠近已有墙角自动吸附并高亮；「开门洞」悬停即高亮目标墙并预览开口宽度；拖拽预览与最终落笔使用同一吸附结果

没有图纸？直接画现场草图

  • 起手：热力图页左侧「1 · 图纸」选一个模板（空白楼层 / 走廊+6 房间 / 开放办公 / 单间 / L 形），点「绘制草图」；不想从头画可直接用模板，之后随时增删
  • 画：展开「1b · 草图编辑」，用「画房间」拖拽勾出区域（自动生成 4 面墙）、「画隔墙」补隔断、「开门洞」在墙上点一下开 0.9 m 通口、「加标注」写房间名；网格吸附与正交可关，支持撤销 / 重做 / 改名 / 改材质
  • 定尺寸：宽度和长度可分别手工输入、拖动滑杆、选择常用尺寸或随机生成；程序自动维护 X/Y 两个比例尺，也可沿已知长度用「比例尺标定」精修
  • 定安装：先设置新 AP 默认离地高度和安装方式，也可在右侧 AP 清单逐台调整吸顶、侧挂、吊杆、抱杆、桌面或机柜安装；一键可把默认参数应用到全部 AP
  • 算得准：模型按终端参考高度 1.2 m 计算三维距离，并叠加安装方式方向损耗；草图墙进入 ITU-R P.1238 多墙模型，相邻共边自动去重，门洞会切开墙段让信号穿过
  • 勘测联动：草图自动同步成「现场勘测」页的底图，两页同为 1000×700 坐标系，点击打点位置与 AP 坐标严格对齐；也可点「同步到勘测页」手动刷新
  • 收尾：点「完成 / 返回布点」后即可放置 AP、录入实测点、计算热力图；「保存项目」会把矢量草图一并存下，下次加载仍可继续编辑；「导出草图 PNG」可贴进报告
  • 边界：这是示意草图，不是测绘成果，没有真实地理坐标；墙体材质与厚度是人工估计，结论仍需现场实测打点校正

型号库能做什么

  • 993 条逐 SKU 记录、20 家厂商，含 615 条老旧 / EOL / 历史品牌型号
  • 按产地、类别、厂商、世代、生命周期、能力层级、核实状态筛选，可导出当前结果 CSV
  • 点开详情可看：最低控制器版本、管理平面形态、适配器 ID、核实日期与备注——这些正是 P1 做适配器路由与兼容校验的入口
  • 核实状态分「已核实 / 待核对 / 预留」，待核对条目不要当作确认事实使用

SSID 怎么用

  • 顶部「当前 SSID」是全局分析对象，切换后热力图、现场连接、干扰分析与诊断会一起变
  • 「SSID 配置」页可新建 / 编辑 / 删除 SSID：设频段（双频 / 2.4 / 5 / 6）、VLAN、安全套件、广播与启用状态、最小接入 RSSI、最大客户端数
  • 「广播该 SSID 的 AP」不勾表示所有 AP 都广播；勾选后热力图只用这些 AP 计算，可用于验证语音 / IoT / AGV 的专项覆盖
  • 「双频」沿用热力图页所选频段；单频 SSID 会覆盖该选择，用对应频段的传播参数（页面会提示）
  • 现场连接页可按 SSID 筛选终端，SSID 配置页下方有各 SSID 的终端数、健康率与平均信号
  • 配置保存在 %APPDATA%\WirelessNetOptimizer\ssids.json，重启后保留；「恢复默认」可一键还原
  • 用本机正在连的 SSID：SSID 配置页顶部「本机无线连接」通过 Windows netsh wlan show interfaces 只读读取当前 SSID / BSSID / 波段 / 信道 / 信号，默认在启动时自动加入列表并设为分析对象；断网可用、不联网、不修改无线配置。也可从本机已保存的配置文件里选一个；取消勾选「启动时自动采用本机 SSID」可关闭

干扰分析与现场状态怎么用

  • 干扰分析：2.4G 频谱柱中蓝=AP 占用、橙=非 Wi-Fi 干扰、绿框=1/6/11 非重叠信道；干扰源清单可增删，右侧给出同信道冲突与信道重规划建议，「应用建议信道」会写回热力图的 AP
  • 去热力图看干扰影响：自动切到 SINR 图层并按现场干扰重算，可直观看到干扰源周边由绿转橙红（噪声抬升 → SNR 下降）
  • 现场连接：每 2 秒刷新终端 RSSI / SNR / MCS / 重传 / 流量 / 认证 / 漫游，右侧是事件流；支持暂停、筛选、点行看详情
  • 联动：「在热力图上定位」把终端按状态着色标到图纸；「用现场数据诊断」把聚合证据带入故障排查并直接推理；单个终端详情也可单独诊断
  • 这两块当前是模拟采集，字段按 SNMP v2c / WLC API 客户端表建模，P1 接现网时替换采集层即可，前端无需改动

移动漫游怎么测

  • 前提：本机连上被测 SSID（走无线，不能是有线）；选好采样间隔（默认 1 秒）后点「开始监测」
  • 怎么走：拿着笔记本沿用户投诉路线走一遍，页面每秒刷新当前 SSID / 接入点 / 信号；BSSID 一变，时间线立刻出现一条漫游记录（从哪个 AP 切到哪个、驻留多久、信号变化多少 dB）
  • 看什么：信号轨迹低于 -67 开始影响高速率、低于 -75 属边缘；切换后仍落在 -70 以下记为「弱切换」；同 SSID 有强 8 dB 以上的邻居却长时间不切，会提示粘滞（常见 802.11k/v 未启用）
  • 信道拥挤：显示当前信道的干扰指数、射频数、AP 上报利用率与本频段排名；旁边列出本频段各信道占用，▲ 是你所在的信道
  • 留档：点「导出 CSV」保存漫游事件表；同一路线多走两遍可对比优化前后差异
  • 注意：周边 BSS 缓存不足时会自动补一次主动扫描（约 4-8 秒，可能瞬断），落在扫描窗口内的事件会标注「可能为扫描伪影」，判读时剔除

现场勘测与智能审计怎么用

  • 准备：在「热力图」页上传楼层图，或直接画一张现场草图（会自动同步为本页底图），并放置 AP（校准传播模型要用）；在「空口扫描」页至少扫一次，或直接勾选勘测页的「每个点位重新扫描」
  • 走测：打开「现场勘测」→ 填会话名 → 选验收模板（语音 / 通用数据 / 高密度 / 定位）→ 拿笔记本沿路线走，每到一点在图纸上点一下。程序会记录该点真实 SSID、BSSID、RSSI、SINR、信道、干扰指数与可见射频数
  • 看图层：切换「RSSI / SINR / 信道干扰 / 需求达标 / 可见射频数 / 信道利用率 / SNR / 干扰余量损耗」八个图层，绿=好、黄=边缘、红=差；越靠近实测点颜色越实，远处淡色表示插值置信度低。SNR 与 SINR 相减即干扰吃掉的信号余量
  • 校准：≥3 个点位后点「用实测点校准」，程序反推路径损耗指数 n 与 1m 损耗 PL0，可一键应用到预测热力图。若拟合值落在边界或改善 <0.5 dB，界面会提示不要采用
  • 审计：「智能审计」页汇总自动问题清单（严重度 / 证据 / 影响 / 处置）、信道 / 带宽 / 功率建议与安全核查；点「重新扫描并审计」可刷新到当前空口状态
  • 交付：「生成勘测报告」打开一份单文件离线 HTML（执行摘要 / 逐点验收 / 问题清单 / 信道规划 / 安全审计 / 模型校准 / 口径与边界 / 多楼层合订 / 优化前后对比），浏览器直接打印成 PDF 即可给客户或存档；点位可另存 CSV

报告模板、DXF 与规则自定义（v0.12 新增）

  • 报告模板：勘测页展开「高级」→ 填标题 / 机构 / 项目 / 勘测人 / 复核人 / 页脚，可上传公司 Logo（约 320 KB 内）、关掉签署栏或保密标记；保存后所有报告自动套用，配置只存本机
  • 多楼层合订：登记楼层（名称 + 实际宽度）会自动切换为同名勘测会话；勾选多个会话点「生成合订报告」，每个楼层单独算点位与达标率，再汇总成一张表，不会把不同楼层的点混在一起插值
  • 优化前后对比：整改前「保存基线」，整改后沿同一路线复测再存一份；选两份点「对比」看达标率 / 健康分 / 问题清单 / 逐点 RSSI 的变化，「把对比写进报告」会追加一章
  • 点位 CSV 批量导入：先下载模板，按 1000×700 图纸坐标填好历史记录，一次性导入当前会话；中英文表头都认，缺坐标的行会跳过并给出行号
  • 走测路径：实测点位图按采集顺序连虚线 + 方向箭头，是「点击序列」不是 GPS 轨迹，可在高级面板关掉
  • 审计规则自定义：智能审计页展开「规则设置」，20 条规则（含 PMF 缺失、802.11r/k/v 漫游能力、OWE、WPA3 过渡模式）可逐条停用或改严重度；保存后问题清单、健康分与报告按同一口径重算，也可一键恢复默认
  • DXF 导入：热力图「1 · 图纸」→「导入 DXF」，读取 ASCII DXF 的 LINE / LWPOLYLINE / POLYLINE / ARC / CIRCLE 线段，按包围盒等比铺进 1000×700，图层名推断初始材质；柱 / 设备圆与门弧等非墙体符号会自动跳过。导入后必须人工修墙：用「选择 / 改名」核对材质、删掉标注线、在墙上开门洞。不支持二进制 DXF、块参照 INSERT、填充与三维实体，也不自动识别门洞
  • 深色主题：顶栏「◐ 深色」切换，偏好存浏览器本地；图纸画布仍按白纸显示，便于对照现场纸质图

本机诊断、能力矩阵与离线交付（v0.13 新增）

  • 本机诊断页：只读解析 netsh wlan show drivers（网卡 / 驱动 / 无线电类型）、show profiles + 逐条 show profile name=X（认证 / 加密，绝不读取明文密钥）、ipconfig /all（IPv4 / 网关 / DNS / DHCP）、Windows 已生成的 WlanReport 历史连接报告；合成本机侧问题清单。不 ping、不联网、不改配置
  • AP 能力矩阵：空口扫描后逐 BSS 列出 WPA3-SAE / OWE / PMF / 802.11r·k·v / MBSSID / WMM / 6 GHz / Wi-Fi 6 / 加密套件 / 厂商 OUI / DTIM / BSS Color。能力由 Beacon IE 位推断，未做关联协商验证，厂商实现可能有差异
  • 扫描历史趋势：每次扫描自动把汇总快照写入本地 JSONL，可切 7 种指标看折线、按小时聚合、导出 CSV、清空；用于对比不同时段 / 不同点位的空口变化，不上传任何数据
  • Word 报告：勘测页「高级 → 离线交付」点「导出 Word 报告」，用纯标准库按 OOXML 生成 .docx，自动套用报告模板，可离线编辑、盖章、归档
  • 项目备份：一键导出全量用户数据 zip（SSID / 点位 / 草图 / 图纸 / 模板 / 规则 / 历史），选择 zip 可恢复；恢复会覆盖同名文件并清空内存缓存，需刷新页面
  • 图片识别候选墙：热力图「1 · 图纸 → 图片识别候选墙」用灰度 + 水平/垂直连续暗像素游程从底图提取直线段，写入草图墙表。这是候选线段、必须人工修墙（核对材质、删标注线、开门洞），不做 AI 语义识别、不认门弧与填充

当前边界（重要）

  • 本版是 P0 可运行原型：设备 / 终端 / 控制器侧仍是模拟数据，不轮询 SNMP、不调用 WLC/AP API、不采集客户端数据；空口扫描、移动漫游、勘测打点是本机网卡的真实只读采集。定位仍是单机离线、零外网、纯只读，未放开主动业务测试与配置下发
  • 顶部「官方文档库」可按厂商 / 专题 / 核实状态与关键词检索全部内置文献，并可点回诊断结论引用的出处
  • 空口扫描是真实数据：通过 Windows 原生 WLAN 接口扫描本空间 BSS（含隐藏 SSID），给出 RSSI / SNR / SINR、信道干扰指数、区域评分与整改建议，可把扫到的 SSID 一键导入为分析对象
  • 移动漫游是真实数据：本机当前关联、漫游事件、信号轨迹与当前信道拥挤全部来自这台电脑的无线网卡，只读采集；切换耗时是采样级观测值，不是空口时延
  • 故障排查是规则推理演示，不主动采集设备日志与 trap；但新增的「WLC 诊断」页可读取你粘贴的日志 / 配置 / 抓包文本做离线匹配，结论需现场复核
  • WLC 诊断与官方文档库完全离线：官方码表、125 篇文献索引与中文提炼、138 条命令、40 个诊断剧本、22 套话术、8 套 SOP 已编译进 exe，运行时不访问外网；官方链接仅作展示，点开与否由你决定
  • 现场勘测与智能审计是真实数据：点位来自本机网卡的空口快照 + 图纸点击坐标；需求阈值是公开工程经验值（非厂商认证标准），报告会原样列出所用口径
  • 与 Ekahau / AirMagnet 的硬差距：Sidekick / Spectrum XT 有专用射频前端，能出实时 FFT 频谱并识别蓝牙、微波炉、雷达等非 Wi-Fi 干扰源；普通网卡只解析 Beacon/Probe，本软件的干扰指数是「可见射频数 + 频率区间重叠 + AP 上报 BSS Load」的工程估计，不做原始频谱分析
  • 审计里的「未登记 SSID」只表示没出现在项目 SSID 清单里；空口无法判断 AP 是否接入内部有线网，不等同于控制器侧基于有线发现判定的 Rogue AP，需现场核对
  • 信道规划是基于本次单点扫描的建议，不是控制器下发的配置；整层规划应由 RRM/DCA 统一执行，避免逐台手工改造成信道震荡
  • 热力图是单楼层二维模型，未做多层楼板衰减、3D 天线方向图与 MLO/6 GHz AFC；勘测插值图层在点少时置信度低，界面会用淡色标注。DXF / 手绘草图是示意图纸而非测绘成果，无真实地理坐标，墙体为零厚度线段、材质损耗取经验值，仍需实测打点校正
  • 型号库覆盖公开主流产品线，不穷举地区管制域后缀；上线前需按现网采购清单核对一次
  • 完整设计与验收指标见右上角「方案书 v0.18」第 16.14–16.21 节
